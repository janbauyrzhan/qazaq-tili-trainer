# Til Bridge

Интерактивная платформа для изучения казахского и русского языков с поддержкой китайского языка.

## Курс

Каждое направление состоит из трёх модулей:

1. **Буквы** — узнавание букв и произношение звуков (6 уроков).
2. **Слова** — словарь по темам «Семья», «Школа», «Цвета» и «Действия» (5 уроков).
3. **Предложения** — порядок слов, формы глаголов и вопросы (5 уроков).

## Возможности

- теория, примеры и короткая проверка в каждом уроке;
- регистрация без пароля: имя и выбранное направление;
- сохранение профиля, диагностики и прогресса в `localStorage` браузера;
- диагностика из 8 вопросов с рекомендацией стартового модуля;
- учебный словарь китайский ↔ казахский ↔ русский;
- озвучивание только через голос, установленный для нужного языка; если подходящего голоса нет, звук не запускается;
- адаптивная версия для телефона и компьютера.

Регистрация не создаёт серверный аккаунт. Имя и пройденные уроки остаются только в браузере на этом устройстве. Очистка данных браузера удалит локально сохранённый прогресс.

## Запуск

Откройте `index.html` или запустите локальный статический сервер:

```bash
python -m http.server 4173
```
