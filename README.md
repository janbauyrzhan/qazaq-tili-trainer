# Til Bridge

Интерактивная платформа для изучения казахского и русского языков с поддержкой китайского языка.

## Курс

Каждое направление состоит из трёх модулей:

1. **Буквы** — узнавание букв и произношение звуков (6 уроков).
2. **Слова** — словарь по темам «Семья», «Школа», «Цвета» и «Действия» (5 уроков).
3. **Предложения** — порядок слов, формы глаголов и вопросы (5 уроков).

## Возможности

- отдельные страницы конспекта и теста: 32 урока, 64 вопроса с объяснениями;
- приветственное окно при первом посещении;
- регистрация без пароля: имя и выбранное направление;
- сохранение профиля, проверки знаний и прогресса в `localStorage` браузера;
- проверка знаний из 6 вопросов отдельно для каждого языка (не официальный уровень владения языком);
- урок завершается после двух правильных ответов; после ошибки доступно повторение;
- учебный словарь китайский ↔ казахский ↔ русский;
- озвучивание только через голос, установленный для нужного языка; если подходящего голоса нет, звук не запускается;
- адаптивная версия для телефона и компьютера.

Регистрация не создаёт серверный аккаунт. Имя и пройденные уроки остаются только в браузере на этом устройстве. Очистка данных браузера удалит локально сохранённый прогресс.

Один браузер хранит один профиль: изменение имени не создаёт отдельного ученика. Старые отметки прохождения сохраняются. Серверной авторизации нет.

В уроках и тестах справа размещён «ИИ-учитель» (на телефоне — под заданием). Чат обращается к серверной функции /api/chat, которая вызывает Google Gemini. Ключ остаётся на сервере. В Google передаются вопрос, до трёх предыдущих обменов сообщениями и учебный материал текущего урока. Имя профиля и прогресс не передаются. Переписка живёт в памяти вкладки и исчезает после перезагрузки. В режиме теста история не передаётся, а инструкция просит давать подсказки без готового ответа; это педагогическая инструкция, не гарантия поведения модели.

## Подключение Gemini

1. Создать ключ в Google AI Studio: https://aistudio.google.com/api-keys
2. Vercel → проект qazaq-tili-trainer → Settings → Environment Variables.
3. Добавить GEMINI_API_KEY, значение — ключ, тип Secret (Sensitive), окружение Production. Не добавлять публичный префикс.
4. Необязательно: GEMINI_MODEL, по умолчанию gemini-3.8-flash. Можно выбрать доступную для своего проекта модель с generateContent. При временной недоступности основной модели сервер пробует gemini-3.5-flash-lite.
5. Сделать Redeploy. Проверить GET /api/chat: available должен стать true, затем задать вопрос в уроке.

Без ключа сервер возвращает NOT_CONFIGURED; фиктивных ответов нет. Проверка available означает наличие конфигурации, а не валидность ключа или наличие квоты. Локальные секреты держать в .env.local (игнорируется Git); пример имён переменных — .env.example. Статический Python-сервер не запускает API: для полного приложения использовать vercel dev.

Ограничения: 800 символов в вопросе, 32 КБ на запрос, тайм-аут провайдера 20 секунд, до 1536 выходных токенов. Есть дополнительный лимит 8 запросов/минуту на IP в рамках одного экземпляра функции. Он не является общим лимитом расходов: экземпляры Vercel независимы, авторизация отсутствует. Перед широким доступом настройте квоты у провайдера и централизованное ограничение запросов. Оплата сервисов автоматически не включается.

Условия провайдера: https://ai.google.dev/gemini-api/terms — Gemini Developer API имеет ограничение на приложения, ориентированные на пользователей младше 18 лет или вероятно доступные им. Подготовка кода не отменяет это ограничение. Бесплатный и платный сервисы имеют разные условия обработки данных; личные данные в чат не вводить.

Проверка серверного контракта без настоящего ключа: node --test tests/teacher.test.mjs. Настоящий ответ модели требует настроенного ключа и доступной квоты.

## Материалы

Noto Sans хранится в `fonts/` и загружается с самого сайта. Обе версии проверены на наличие Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі. Лицензия SIL OFL включена в `fonts/OFL.txt`. Внешний Google Fonts для отображения казахского текста не требуется.

Краткие конспекты и упражнения составлены для этого проекта своими словами. В уроках есть ссылки для дополнительного чтения: [Soyle](https://www.soyle.kz/?lang=en), [Emle](https://emle.kz), [Грамота.ру](https://gramota.ru/biblioteka/spravochniki/russkij-yazyk-kratkij-teoreticheskij-kurs-dlya-shkolnikov/zvuk-i-bukva). Это вводный тренажёр, не полный учебник и не сертификационный экзамен. Перед использованием в научном исследовании материалы должен проверить преподаватель.

Синтез речи не является эталоном произношения. Отдельные буквы не озвучиваются, чтобы не смешивать названия букв и звуки. Словарь переводит только предусмотренные учебные примеры, не произвольный текст.

## Запуск

Откройте `index.html` или запустите локальный статический сервер:

```bash
python -m http.server 4173
```
