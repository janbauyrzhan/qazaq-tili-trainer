# Til Bridge

Интерактивная платформа для изучения казахского и русского языков с поддержкой китайского языка.

## Курс

Каждое направление состоит из трёх модулей:

1. **Буквы** — узнавание букв и произношение звуков (6 уроков).
2. **Слова** — словарь по темам «Семья», «Школа», «Цвета» и «Действия» (5 уроков).
3. **Предложения** — порядок слов, формы глаголов и вопросы (5 уроков).

## Возможности

- отдельные страницы конспекта и теста: 32 урока, 64 вопроса с объяснениями;
- приветственное окно при первом посещении;
- регистрация без пароля: имя и выбранное направление;
- сохранение профиля, проверки знаний и прогресса в `localStorage` браузера;
- проверка знаний из 6 вопросов отдельно для каждого языка (не официальный уровень владения языком);
- урок завершается после двух правильных ответов; после ошибки доступно повторение;
- учебный словарь китайский ↔ казахский ↔ русский;
- озвучивание только через голос, установленный для нужного языка; если подходящего голоса нет, звук не запускается;
- адаптивная версия для телефона и компьютера.

Регистрация не создаёт серверный аккаунт. Имя и пройденные уроки остаются только в браузере на этом устройстве. Очистка данных браузера удалит локально сохранённый прогресс.

Один браузер хранит один профиль: изменение имени не создаёт отдельного ученика. Старые отметки прохождения сохраняются. API, ИИ и серверная авторизация не подключены.

В уроках и тестах справа размещён интерфейс «ИИ-учитель» (на телефоне — под заданием). Пока API не подключён, он показывает явное уведомление вместо сгенерированных ответов. Вопросы никуда не отправляются; переписка и черновики живут только в памяти текущей вкладки, отдельно для каждого урока, и исчезают при перезагрузке. Есть примеры вопросов, сворачивание и очистка.

## Материалы

Noto Sans хранится в `fonts/` и загружается с самого сайта. Обе версии проверены на наличие Әә Ғғ Ққ Ңң Өө Ұұ Үү Һһ Іі. Лицензия SIL OFL включена в `fonts/OFL.txt`. Внешний Google Fonts для отображения казахского текста не требуется.

Краткие конспекты и упражнения составлены для этого проекта своими словами. В уроках есть ссылки для дополнительного чтения: [Soyle](https://www.soyle.kz/?lang=en), [Emle](https://emle.kz), [Грамота.ру](https://gramota.ru/biblioteka/spravochniki/russkij-yazyk-kratkij-teoreticheskij-kurs-dlya-shkolnikov/zvuk-i-bukva). Это вводный тренажёр, не полный учебник и не сертификационный экзамен. Перед использованием в научном исследовании материалы должен проверить преподаватель.

Синтез речи не является эталоном произношения. Отдельные буквы не озвучиваются, чтобы не смешивать названия букв и звуки. Словарь переводит только предусмотренные учебные примеры, не произвольный текст.

## Запуск

Откройте `index.html` или запустите локальный статический сервер:

```bash
python -m http.server 4173
```
