# Til Bridge

Интерактивная платформа для изучения казахского и русского языков китайскоязычными учениками.

## Структура курса

Каждое языковое направление состоит из трёх последовательных модулей:

1. **Буквы** — распознавание букв и правильное произношение звуков.
2. **Слова** — тематическая лексика: семья, школа, цвета и действия.
3. **Предложения** — формы глагола, порядок слов и вопросы.

В казахском и русском направлениях по 16 уроков: 6 уроков по буквам, 5 по словам и 5 по предложениям.

## Возможности

- теория, примеры и мини-тест в каждом уроке;
- сохранение прогресса в `localStorage` браузера;
- диагностика из 8 заданий с рекомендацией стартового модуля;
- учебный переводчик между китайским, казахским и русским языками;
- озвучивание слов через Web Speech API;
- адаптивная версия для телефона и компьютера.

Сайт не содержит персональных профилей и не отправляет результаты на сервер. Прогресс хранится только в браузере пользователя.

## Запуск

Откройте `index.html` или запустите локальный статический сервер:

```bash
python -m http.server 4173
```
