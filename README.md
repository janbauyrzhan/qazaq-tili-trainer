# Qazaq Tili — diagnostika site

Қандас балалардың қазақ тілінде оқу, тыңдау және жазу дағдыларын дамытуға арналған статикалық веб-тренажер.

## Жергілікті іске қосу

`index.html` файлын браузерде ашыңыз немесе VS Code ішіндегі Live Server кеңейтімін қолданыңыз.

## Жариялау

Жоба тек HTML, CSS және JavaScript қолданады, сондықтан GitHub Pages арқылы тегін жариялауға болады.
