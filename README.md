# Til Bridge

Til Bridge — қытай тілді оқушыларға қазақ және орыс тілдерін кезең-кезеңмен үйрететін ғылыми жобаға арналған интерактивті сайт.

## Мүмкіндіктер

- Қазақ тілі: әріп, сөз, сөйлем және мәтін деңгейлері
- Орыс тілі: буквы, слова, предложения и тексты
- 38 интерактивті сабақ
- Қытайша, қазақша және орысша оқу сөздігі
- Бастапқы және қорытынды диагностика
- Рауан оқушысының демонстрациялық оқу маршруты
- Диагностикалық журнал және CSV экспорты
- Нәтиже динамикасы мен дағдылар картасы

## Іске қосу

Жоба таза HTML, CSS және JavaScript арқылы жасалған. `index.html` файлын браузерде ашуға немесе жергілікті серверді қолдануға болады.

```bash
python -m http.server 4173
```

Содан кейін `http://localhost:4173` мекенжайын ашыңыз.

## Деректер туралы

Рауанның профиліндегі нәтижелер сайттың жұмысын көрсетуге арналған демонстрациялық үлгі. Ғылыми жұмысқа енгізілетін көрсеткіштер нақты оқу журналымен расталуы керек.
